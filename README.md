# DJ Billing Pro

Design a premium, modern, responsive DJ Billing Book web application UI with a professional SaaS dashboard look. The application is built only for a single DJ owner to create invoices and download PDF bills. Keep the design minimal, elegant, and user-friendly. Use Bootstrap 5 design principles with a clean layout, glassmorphism cards, soft shadows, rounded corners (12-16px), smooth hover effects, and premium typography.

Theme:

- DJ-inspired premium business theme

- White primary background

- Royal Purple (#6D28D9) and Electric Blue (#2563EB) as accent colors

- Neon highlights

- Soft glowing effects

- Modern icons

- Professional business appearance

- Responsive desktop-first design

- No dark mode

- No clutter

- Figma and Dribbble quality UI

The application contains ONLY 3 pages.

Split-screen layout.

- Large DJ illustration

- DJ console
